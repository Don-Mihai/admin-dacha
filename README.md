# Админка проектов — Уткина дача

## Краткое описание ПО

Служебное приложение для редактирования данных киосков музея «Уткина дача». Позволяет выбирать проекты из соседних папок, править JSON-файлы (таблицей или текстом) и загружать изображения в `public` выбранного проекта.

## Сценарий работы ПО

### Стартовый экран

Шапка «Админка проектов — Уткина дача». Слева — постоянная боковая панель (drawer), справа — рабочая область с двумя вкладками.

### Боковая панель проектов

- **Обновить список** — перезагружает список проектов.
- Дерево: имя проекта → раскрытие → список JSON-файлов данных.
- Выбор файла загружает его в редактор. При несохранённых изменениях появляется предупреждение перед сменой файла.

### Вкладка «Данные (JSON)»

- Показывается путь `{проект} / {файл}` или подсказка «Выберите файл слева».
- Если JSON — массив объектов: переключатель **Таблица** / **JSON**; при нескольких массивах — выбор массива.
- Редактирование ячеек таблицы или сырого JSON.
- **Сохранить** — проверка валидности и запись файла.

### Вкладка «Загрузка изображений»

- Выбор **Проекта**.
- Поле **Папка в public** (по умолчанию `data/images`).
- **Выбрать файл** → **Загрузить**.
- После загрузки отображается URL и кнопка **Копировать**.
